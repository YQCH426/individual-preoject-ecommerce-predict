# 电商消费避雷数据分析与 AI 可视化平台

> 事前预警 · 事后实锤 · AI 导购 —— 让每一笔订单都有据可依

## 项目简介

网购最大的痛点是**信息不对称**：下单前，我们只能靠几张精修图和一屏"精选好评"做决定，**事前容易冲动**，手指一滑就下单；收货后才发现货不对板、质量翻车，于是陷入**事后频繁退货**的循环——搭进去的是运费、时间和心情。

本平台把电商评论、销量与退货等消费数据转化为可交互的可视化分析，帮助你在**下单前**识别风险、在**退货后**复盘翻车原因，并由 **AI 智能导购**给出最终决策建议，形成"事前 — 事中 — 事后"的完整避雷闭环，把消费决策从"凭感觉"变成"看数据"。

## 核心功能

### 1. 事前预警漏斗图

下单前的风险筛查漏斗。以"候选商品 → 剔除差评集中 → 剔除退货率偏高 → 剔除描述不符 / 虚假宣传 → 可放心下单"逐层过滤，每一层展示被拦截的商品数量与占比。冲动下单之前，你就能直观看到：**这一单，本来可以拦下多少雷。**

### 2. 事后实锤词云

退货之后的复盘利器。从真实差评与退货原因文本中提取高频关键词（如"色差""起球""货不对板"），字号越大代表出现次数越多，一眼看清翻车的真正原因；同时可作为与商家沟通、申请退款时的举证参考。

### 3. AI 智能导购

接入 LLM 大语言模型，用一句话说出需求（"预算 500，想买双不磨脚的跑鞋"），AI 结合平台的风险数据与评论洞察，给出**带理由的推荐、风险提示与替代方案**，把"看图下单"变成"问过再买"。

## 技术栈

| 技术 | 用途 |
|---|---|
| **Streamlit** | Web 应用框架，快速搭建交互式数据分析界面 |
| **Plotly** | 交互式可视化（漏斗图、词云等），支持缩放、悬停查看明细 |
| **Pandas** | 数据清洗、聚合与统计分析 |
| **LLM** | 大语言模型 API，驱动 AI 智能导购的对话与推荐 |

## 本地运行指南

### 环境要求

- Python 3.9 及以上
- 已安装 git

### 1. 克隆仓库

```bash
git clone https://github.com/<你的用户名>/ecommerce-predict.git
cd ecommerce-predict
```

### 2. 创建虚拟环境并安装依赖

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

pip install -r requirements.txt
```

### 3. 配置 LLM API Key（AI 智能导购需要）

在项目根目录新建 `.env` 文件，填入你的密钥：

```text
DEEPSEEK_API_KEY=你的密钥
```

> `.env` 已在 `.gitignore` 中被忽略，**不会被提交到仓库**，请勿将密钥直接写入代码。

### 4. 启动应用

```bash
streamlit run app.py
```

浏览器访问 <http://localhost:8501> 即可使用。

### 项目结构

```text
ecommerce-predict/
├── app.py              # Streamlit 应用入口
├── requirements.txt    # 依赖清单
├── .gitignore          # 忽略规则（.env、数据文件等）
└── README.md
```
